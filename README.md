# 积存金持仓管理系统

一个功能完善的积存金投资持仓管理工具，集成实时金价 API，支持多次买入、卖出操作、保本价计算、金价走势图表和卖出收益记录查询。

## 功能特性

### 实时金价

- **实时金价卡片**：从 API 获取并展示当前金价、卖出价、今日最高/最低、开盘价，深色主题醒目清晰
- **价格涨跌指示**：红色上涨 / 绿色下跌，直观展示金价变化
- **自动刷新**：每 60 分钟自动拉取最新金价，也可通过刷新按钮手动刷新
- **手动刷新按钮**：圆形箭头图标按钮，位于小时走势图右上角，带加载旋转动画、成功/失败状态反馈和 Toast 提示

### 金价走势图表

- **双维度同屏展示**：当日小时走势（金色折线）+ 近 7 日走势（蓝色折线），清晰区分不同时间维度
- **交互功能**：点击数据点显示具体时间和价格，触控热区优化（pointHitRadius: 20px）
- **数据持久化**：逐时数据保留 7 天，每日汇总保留 90 天，每周自动清理过期数据
- **Chart.js**：使用 Chart.js 4.x 渲染，300ms 快速动画，移动端性能优异

### 持仓管理

- **多次买入记录**：支持分批次买入，记录每次买入的时间、价格、克数和手续费
- **数据持久化**：使用浏览器 localStorage 保存数据，刷新不丢失
- **卖出操作**：支持按克数或按金额两种卖出方式，分段控件样式清晰区分选中状态
- **自动获取卖出价**：点击"获取实时价"按钮自动填入当前实时卖出价格，无需手动输入
- **持仓统计**：实时显示总持仓克数、总投入金额、加权平均成本
- **保本卖出价**：根据持仓成本自动计算保本价格
- **买入记录管理**：支持查看、删除单条记录或清空全部

### 卖出收益记录

- **收益汇总卡片**：展示累计卖出次数、总金额、总收益、平均收益率
- **时间筛选**：支持全部、今日、本周、本月、自定义日期范围筛选
- **多维排序**：按时间、收益金额、收益率升序/降序排列
- **分页加载**：每页 5 条记录，智能页码显示
- **收益明细**：包含卖出时间、卖出价、成本价、克数、金额、手续费、收益金额和收益率
- **视觉区分**：盈利显示红色，亏损显示绿色（符合中国股市习惯）

### 移动端适配

- **响应式设计**：320px–428px 移动端宽度自适应，所有按钮触控区域 ≥44px
- **跨平台字体**：使用系统字体栈，iOS/Android 原生字体渲染
- **触控优化**：`touch-action: manipulation` 消除 300ms 延迟，`-webkit-tap-highlight-color` 透明
- **表格滑动提示**：移动端显示"← 左右滑动查看完整表格 →"引导

## 计算公式

### 持仓管理

```
加权平均成本 = Σ(买入金额 + 买入手续费) / 总克数
保本卖出价 = 加权平均成本 / (1 - 卖出手续费率/100)
```

### 卖出收益

```
成本价格 = 卖出时记录的加权平均成本价格
收益金额 = 卖出金额 - 卖出手续费 - (卖出克数 × 成本价格)
收益率 = 收益金额 / (卖出克数 × 成本价格) × 100%
```

**注意**：卖出时会记录当时的加权平均成本价格，确保收益计算准确反映卖出时的真实情况。

## 金价 API

使用 `https://tmini.net/api/gold-price` 接口获取实时黄金价格数据，包含：

| 字段 | 说明 |
|------|------|
| `today_price` | 今日当前金价（元/克） |
| `sell_price` | 卖出价格（元/克） |
| `high_price` | 今日最高价（元/克） |
| `low_price` | 今日最低价（元/克） |
| `updated` | 数据更新时间 |

## 数据存储

所有数据保存在浏览器的 localStorage 中：

| Key | 说明 | 保留时长 |
|-----|------|---------|
| `goldTradeData` | 买入/卖出记录 | 永久 |
| `goldPriceHistory` | 每小时金价快照 | 7 天 |
| `goldPriceDaily` | 每日金价汇总 | 90 天 |
| `goldPriceLastWeeklyUpdate` | 上次周更新清理时间戳 | 永久 |

## 性能优化

- **DocumentFragment**：批量创建 DOM 节点，减少重排重绘
- **渲染防抖**：80ms 延迟，避免频繁渲染
- **requestAnimationFrame**：在浏览器最佳时机渲染
- **`chart.update('none')`**：跳过动画直接更新图表数据
- **汇总数据缓存**：避免重复计算
- **for 循环替代 reduce**：遍历性能提升约 30%
- **智能分页显示**：只显示 5 个页码 + 省略号

## 注意事项

1. 数据仅保存在本地浏览器中，更换浏览器或清除浏览器数据会导致数据丢失
2. 买入手续费率默认为 0%，卖出手续费率默认为 0.4%，可根据实际情况调整
3. 卖出时采用 FIFO（先进先出）原则扣减持仓
4. 金价走势数据依赖每小时自动刷新，首次打开需等待一次 API 请求
5. 图表支持离线查看历史数据，但实时更新需要网络连接
