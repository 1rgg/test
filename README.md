# 积存金收益计算器

一个功能完善的积存金投资收益计算工具，支持单次计算和多次买入持仓管理。

## 功能特性

### 单次计算模式

- **按克数计算**：输入买入价格、卖出价格和克数，计算收益
- **按金额计算**：输入买入价格、卖出价格和购买总金额，计算收益
- **手续费计算**：支持自定义买入/卖出手续费率
- **保本价提示**：自动计算并显示保本卖出价格

### 持仓管理模式

- **多次买入记录**：支持分批次买入，记录每次买入的时间、价格、克数和手续费
- **数据持久化**：使用浏览器 localStorage 保存数据，刷新不丢失
- **卖出操作**：支持按克数或按金额两种卖出方式
- **持仓统计**：实时显示总持仓克数、总投入金额、加权平均成本
- **保本卖出价**：根据持仓成本自动计算保本价格
- **买入记录管理**：支持查看、删除单条记录或清空全部

## 使用方法

### 在线使用

直接在浏览器中打开 `index.html` 文件即可使用。

### 本地运行

```bash
# 使用 Python 启动本地服务器
python -m http.server 8080

# 然后在浏览器中访问
# http://localhost:8080/index.html
```

## 计算公式

### 单次计算

```
买入总金额 = 买入价格 × 买入克数
买入手续费 = 买入总金额 × 买入手续费率 / 100
卖出总金额 = 卖出价格 × 卖出克数
卖出手续费 = 卖出总金额 × 卖出手续费率 / 100
净收益 = (卖出总金额 - 买入总金额) - (买入手续费 + 卖出手续费)
保本卖出价 = 买入价格 × (1 + 买入手续费率/100) / (1 - 卖出手续费率/100)
```

### 持仓管理

```
加权平均成本 = Σ(买入金额 + 买入手续费) / 总克数
保本卖出价 = 加权平均成本 / (1 - 卖出手续费率/100)
```

## 数据存储

所有数据保存在浏览器的 localStorage 中，key 为 `goldTradeData`。

数据结构：
```json
{
  "buyRecords": [
    {
      "id": "唯一标识",
      "timestamp": "买入时间",
      "price": "买入单价",
      "weight": "买入克数",
      "amount": "买入金额",
      "feeRate": "手续费率",
      "fee": "手续费",
      "remainingWeight": "剩余克数"
    }
  ],
  "sellRecords": [
    {
      "id": "唯一标识",
      "timestamp": "卖出时间",
      "price": "卖出单价",
      "weight": "卖出克数",
      "amount": "卖出金额",
      "feeRate": "手续费率",
      "fee": "手续费"
    }
  ]
}
```

## 注意事项

1. 数据仅保存在本地浏览器中，更换浏览器或清除浏览器数据会导致数据丢失
2. 手续费率默认为 0.1%，可根据实际情况调整
3. 卖出时采用 FIFO（先进先出）原则扣减持仓
